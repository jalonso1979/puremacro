## 2024-06-25 - Pandas iteration optimizations
**Learning:** In pandas, `.iterrows()` is extremely slow for large matrices. When doing mathematical operations mapping rows to arrays, `to_numpy().reshape()` or `.itertuples(name=None)` can speed up execution significantly (e.g. going from ~6s to ~0.1s for 10k rows in `_quarterly_chain`). Removing an unused assignment with `ruff --fix` on `F_t = -np.log(...)` leaves the computation. If the computation is expensive and unused, it should be deleted.
**Action:** Always prefer `to_numpy` for bulk vector operations, and `.itertuples()` when iteration is necessary. When using `ruff check --fix` for unused variables, manually remove expensive lingering computations.
