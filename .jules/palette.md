## 2024-05-15 - Inline HTML Security and Accessibility
**Learning:** When generating inline HTML elements for Jupyter notebook output (e.g., via `IPython.display.HTML`), ensuring that external links and decorative icons are handled correctly is critical for both security and accessibility. Using `target="_blank"` without `rel="noopener noreferrer"` presents a security risk by giving the newly opened page access to the window object of the original page. Additionally, screen readers often misinterpret standalone decorative symbols (like emojis or arrows).
**Action:** When creating HTML that includes external links opening in new tabs, always add `rel="noopener noreferrer"`. Also, provide explicit `aria-label`s for the links, and wrap any decorative symbols (like 🚀 or ↗) in a `<span aria-hidden="true">` to prevent screen readers from announcing confusing characters.
