💡 What
- Removed the `aria-label` attribute from the "CSV" download button, keeping only the `title` attribute for tooltips.
- Refactored `MAV.segmented` to dynamically assign an `id` to its label `span` and apply `aria-labelledby` directly to the `role="group"` container.

🎯 Why
- Applying an `aria-label` to the CSV button was overriding its text content ("CSV"), creating a conflict that violated WCAG 2.5.3 (Label in Name).
- Assigning `aria-label` dynamically during the render loop for grouped UI controls is a brittle pattern. Semantically linking the visible label using `aria-labelledby` with a unique ID provides robust, statically structured labeling for screen readers parsing custom groupings.

📸 Before/After
*(Visual UI remains identical, DOM structure improved for screen readers)*

♿ Accessibility
- Fixed WCAG 2.5.3 compliance on the CSV download button.
- Improved context and semantic structure for users relying on screen readers to navigate grouped controls like language toggles.
