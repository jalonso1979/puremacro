Cómo usarlosHow to use them

  • Empieza por la pregunta del título y haz una predicción antes de mover nada.Start with the question in the title and make a prediction before moving anything.
  • Sigue los experimentos de «Qué probar»: cada uno aísla una idea de la unidad.Follow the "Things to try" experiments: each one isolates one idea from the unit.
  • Cada gráfica tiene tabla y CSV. La matemática está al pie, y el cuaderno de Colab reproduce el cálculo en Python.Every chart has a table and a CSV. The math is at the bottom, and the Colab notebook reproduces the computation in Python.

Con qué están hechosWhat they are built with

Los cálculos corren en JavaScript dentro de la página y se validaron contra puremacro, la biblioteca de Python del curso. Los datos son instantáneas congeladas de fuentes públicas; cada laboratorio cita la suya.The computations run in JavaScript inside the page and were validated against puremacro, the course’s Python library. The data are frozen snapshots from public sources; each lab cites its own.
