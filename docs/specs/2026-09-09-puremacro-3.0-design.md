# `puremacro 3.0` — Past Dynare: Analytic Gradients, HMC/NUTS & Sequence-Space HANK

**Status:** Approved Specification — 2026-09-09.  
**Target release:** 3.0.0 (Pillars 1, 2, 3).  
**Baseline:** puremacro 2.9.0 (Full Dynare operational surface, spectral filtering, extended path, Waggoner-Zha conditional forecasting, shock groups decomposition, automated parity dashboard, 1,064+ green tests).  
**Driving lens:** Transition puremacro from *achieving Dynare parity* to *surpassing legacy toolchains*: exact analytical likelihood gradients for high-dimensional gradient-based estimation, pure-Python Hamiltonian Monte Carlo and No-U-Turn Sampler (HMC/NUTS), and native heterogeneous agent (HANK) sequence-space integration directly in `.mod` workflows, strictly adhering to the zero-dependency Pyodide four-package contract (`numpy`, `scipy`, `pandas`, `matplotlib`).

---

## 1. Motivation & Background

With `puremacro 2.9.0`, the package achieved complete operational parity with Dynare:
- **Tier 0 (2.7.0)**: Clean AST parser, macro preprocessor (`@#for`, `@#if`, `@#define`), symbolic derivatives, and 165x order-2 Sylvester speedup.
- **Tier 1 (2.6.0)**: End-to-end `.mod` estimation, diagnostics (`check`, `resid`, `model_diagnostics`), identification analysis (Iskrev 2010), and optimal policy (`osr`, discretionary, commitment).
- **Tier 2 (2.8.0)**: Order-3 perturbation with Andreasen pruning, Mixed Complementarity Problems (MCP / ZLB), 4-regime OccBin, Piecewise Kalman Filter, Sequential Monte Carlo (SMC), and nonlinear Ramsey policy.
- **Tier 3 (2.9.0)**: Spectral HP and bandpass filtering, one-sided recursive Kalman HP filter, Fair-Taylor Extended Path, Waggoner-Zha conditional forecasting, shock groups decomposition, and the automated CI Parity Dashboard.

Legacy macroeconomic software (Dynare / MATLAB / Dynare++), however, remains encumbered by major architectural bottlenecks:
1. **Random-Walk MCMC Scales Poorly**: Medium- and large-scale DSGE models (35+ estimated parameters, e.g. Smets-Wouters 2007) require hundreds of thousands of Random-Walk Metropolis-Hastings (RWMH) draws to explore high-dimensional degenerate posteriors, requiring hours of compute and yielding low effective sample sizes ($ESS < 2\%$).
2. **Absence of Exact Likelihood Gradients**: While modern Bayesian statistics has standardized on Hamiltonian Monte Carlo (HMC) and the No-U-Turn Sampler (NUTS), DSGE models could not leverage NUTS because finite-difference likelihood gradients over a Kalman filter are prohibitively slow ($2K$ likelihood evaluations per step) and numerically noisy.
3. **The Representative-Agent Wall**: Modern frontier macroeconomics increasingly relies on Heterogeneous Agent New Keynesian (HANK) models. Dynare cannot natively solve or simulate sequence-space heterogeneous agent models without clumsy external hacks.

`puremacro 3.0` solves these three challenges natively in pure Python under the strict four-package contract.

## 3. Pillar 1: Exact Analytic Likelihood Gradients ($\nabla_\theta \ln L$)

### 1.1 Structural Parameter Sensitivity of the Decision Rules
The structural rational-expectations system parsed by the AST is:
$$E_t \left[ f(y_{t+1}, y_t, y_{t-1}, u_t; \theta) \right] = 0$$

Around the deterministic steady state $y^*$, the first-order perturbation satisfies:
$$A_+(\theta) y_{t+1} + A_0(\theta) y_t + A_-(\theta) y_{t-1} + B_u(\theta) u_t = 0$$

Let the first-order recursive equilibrium law of motion be:
$$y_t = G(\theta) y_{t-1} + N(\theta) u_t$$
where the state transition blocks satisfy the quadratic matrix equation:
$$\mathcal{F}(G; \theta) \equiv A_+(\theta) G(\theta)^2 + A_0(\theta) G(\theta) + A_-(\theta) = 0$$

Differentiating $\mathcal{F}(G; \theta) = 0$ with respect to scalar parameter $\theta_j$ via the chain rule gives:
$$(A_0 + A_+ G) \frac{\partial G}{\partial \theta_j} + A_+ \frac{\partial G}{\partial \theta_j} G = - \left( \frac{\partial A_+}{\partial \theta_j} G^2 + \frac{\partial A_0}{\partial \theta_j} G + \frac{\partial A_-}{\partial \theta_j} \right)$$

This is a generalized Sylvester matrix equation of the form:
$$\hat{A} X + B X C = D_j$$
where:
- $\hat{A} = A_0 + A_+ G$ (dimension $N \times N$)
- $B = A_+$ (dimension $N \times N$)
- $C = G$ (dimension $N \times N$)
- $D_j = - \left( \frac{\partial A_+}{\partial \theta_j} G^2 + \frac{\partial A_0}{\partial \theta_j} G + \frac{\partial A_-}{\partial \theta_j} \right)$

Because $C = G$ has eigenvalues strictly inside the unit circle (Blanchard-Kahn stability), this Sylvester system has a unique solution for each parameter $\theta_j$. Moreover, computing the complex Schur decomposition $G = U_G T_G U_G^*$ only once allows solving for $\frac{\partial G}{\partial \theta_j}$ across all $K$ parameters via triangular back-substitution in $O(K \cdot N^3)$, taking $< 1$ ms for all parameters combined.

Similarly, differentiating the shock loading condition:
$$(A_0 + A_+ G) N + B_u = 0$$
yields the exact derivative:
$$\frac{\partial N}{\partial \theta_j} = - (A_0 + A_+ G)^{-1} \left[ \left(\frac{\partial A_0}{\partial \theta_j} + \frac{\partial A_+}{\partial \theta_j} G + A_+ \frac{\partial G}{\partial \theta_j}\right) N + \frac{\partial B_u}{\partial \theta_j} \right]$$

### 1.2 State-Space Derivative Mapping
The StateSpaceModel matrices $T, R, Q, Z, H, d$ are derived from $G, N$, shock covariances $\Sigma_u$, and observation equations $y^{obs}_t = Z y_t + d + \epsilon_t$:
$$\frac{\partial T}{\partial \theta_j} = \frac{\partial G}{\partial \theta_j}[states, states], \quad \frac{\partial R}{\partial \theta_j} = \frac{\partial N}{\partial \theta_j}[states, :]$$
$$\frac{\partial Q}{\partial \theta_j} = \frac{\partial \Sigma_u}{\partial \theta_j}, \quad \frac{\partial Z}{\partial \theta_j} = \dots, \quad \frac{\partial H}{\partial \theta_j} = \dots$$

### 1.3 Forward Kalman Filter Score Recursion
Given Gaussian forecast errors $v_t = y_t - Z a_{t|t-1}$ and error covariances $F_t = Z P_{t|t-1} Z^\top + H$, the log-likelihood is:
$$\ln L(Y \mid \theta) = -\frac{T_{obs} n_y \ln(2\pi)}{2} - \frac{1}{2} \sum_{t=1}^{T_{obs}} \left( \ln |F_t| + v_t^\top F_t^{-1} v_t \right)$$

The exact score gradient $\nabla_\theta \ln L$ is computed in a single forward pass without storing all past history:
$$\frac{\partial \ln L}{\partial \theta_j} = -\frac{1}{2} \sum_{t=1}^{T_{obs}} \left[ \operatorname{tr}\left( F_t^{-1} \frac{\partial F_t}{\partial \theta_j} \right) + 2 v_t^\top F_t^{-1} \frac{\partial v_t}{\partial \theta_j} - v_t^\top F_t^{-1} \frac{\partial F_t}{\partial \theta_j} F_t^{-1} v_t \right]$$

The state and covariance forward sensitivities satisfy:
$$\frac{\partial v_t}{\partial \theta_j} = - \frac{\partial Z}{\partial \theta_j} a_{t|t-1} - Z \frac{\partial a_{t|t-1}}{\partial \theta_j} - \frac{\partial d}{\partial \theta_j}$$
$$\frac{\partial F_t}{\partial \theta_j} = \frac{\partial Z}{\partial \theta_j} P_{t|t-1} Z^\top + Z \frac{\partial P_{t|t-1}}{\partial \theta_j} Z^\top + Z P_{t|t-1} \left(\frac{\partial Z}{\partial \theta_j}\right)^\top + \frac{\partial H}{\partial \theta_j}$$

With Kalman gain $K_t = T P_{t|t-1} Z^\top F_t^{-1}$:
$$\frac{\partial a_{t+1|t}}{\partial \theta_j} = \frac{\partial T}{\partial \theta_j} a_{t|t-1} + T \frac{\partial a_{t|t-1}}{\partial \theta_j} + \frac{\partial K_t}{\partial \theta_j} v_t + K_t \frac{\partial v_t}{\partial \theta_j} + \frac{\partial c}{\partial \theta_j}$$
$$\frac{\partial P_{t+1|t}}{\partial \theta_j} = \frac{\partial T}{\partial \theta_j} P_{t|t-1} (T - K_t Z)^\top + T \frac{\partial P_{t|t-1}}{\partial \theta_j} (T - K_t Z)^\top + T P_{t|t-1} \frac{\partial (T - K_t Z)^\top}{\partial \theta_j} + \frac{\partial (R Q R^\top)}{\partial \theta_j}$$

The initial sensitivities $\frac{\partial a_0}{\partial \theta_j}$ and $\frac{\partial P_0}{\partial \theta_j}$ are found by differentiating the discrete Lyapunov equation $P_0 = T P_0 T^\top + R Q R^\top$:
$$\frac{\partial P_0}{\partial \theta_j} - T \frac{\partial P_0}{\partial \theta_j} T^\top = \frac{\partial T}{\partial \theta_j} P_0 T^\top + T P_0 \left(\frac{\partial T}{\partial \theta_j}\right)^\top + \frac{\partial (R Q R^\top)}{\partial \theta_j}$$
which is a discrete Lyapunov equation solved directly via `scipy.linalg.solve_discrete_lyapunov`.

## 4. Pillar 2: Pure-Python Hamiltonian Monte Carlo & NUTS

### 2.1 The No-U-Turn Sampler Algorithm
Implemented in `puremacro/dsge/nuts.py`:
1. **Target Distribution**:
   $$\mathcal{L}(\theta) = \ln p(\theta \mid Y) = \ln L(Y \mid \theta) + \ln p(\theta)$$
   $$\nabla_\theta \mathcal{L}(\theta) = \nabla_\theta \ln L(Y \mid \theta) + \nabla_\theta \ln p(\theta)$$
   where $\nabla_\theta \ln p(\theta)$ is evaluated analytically from standard DSGE prior distributions (Beta, Gamma, InvGamma, Normal, Uniform).

2. **Phase Space & Symplectic Leapfrog**:
   Momenta $p \sim \mathcal{N}(0, M)$, where $M$ is a positive-definite mass matrix (diagonal metric $M = \operatorname{diag}(m_1, \dots, m_K)$).
   $$\theta^{(0)} = \theta, \quad p^{(0)} = p$$
   $$\tilde{p} = p + \frac{\epsilon}{2} \nabla_\theta \mathcal{L}(\theta)$$
   $$\theta' = \theta + \epsilon M^{-1} \tilde{p}$$
   $$p' = \tilde{p} + \frac{\epsilon}{2} \nabla_\theta \mathcal{L}(\theta')$$

3. **Recursive Tree Building & U-Turn Stopping Criterion**:
   At each recursion depth $j \in \{0, 1, \dots, j_{max}\}$, choose direction $v \in \{-1, +1\}$ uniformly at random and double the trajectory length. Stop recursive tree expansion when the trajectory begins to turn back on itself:
   $$( \theta^+ - \theta^- )^\top M^{-1} p^+ < 0 \quad \text{or} \quad ( \theta^+ - \theta^- )^\top M^{-1} p^- < 0$$
   or when Hamiltonian divergence occurs:
   $$H(\theta', p') - H(\theta, p) > \Delta_{max} \approx 1000$$

4. **Dual Averaging Step-Size Adaptation (Nesterov 2009 / Hoffman-Gelman 2014)**:
   During warmup iterations $m \le M_{adapt}$, adapt $\epsilon_m$ to match target acceptance probability $\delta^* = 0.80$:
   $$H_m = \left(1 - \frac{1}{m + t_0}\right) H_{m-1} + \frac{1}{m + t_0} (\delta^* - \alpha_m)$$
   $$\ln \epsilon_{m+1} = \mu - \frac{\sqrt{m}}{\gamma} H_m, \quad \ln \bar{\epsilon}_{m+1} = m^{-\kappa} \ln \epsilon_{m+1} + (1 - m^{-\kappa}) \ln \bar{\epsilon}_m$$

5. **Welford Diagonal Mass Matrix Adaptation**:
   Online covariance estimation across adaptation windows (e.g. Stan 75/25/50/100/200/50 window schedule), regularizing with prior variance shrinkage.

## 5. Pillar 3: Heterogeneous Agents Bridge (Sequence-Space HANK)

### 3.1 `.mod` Syntax Extension
The Dynare parser in `puremacro/dsge/dynare.py` is extended to support `hetagent_block`:
```dynare
var Y C I K w r pi;
varexo eps_a eps_m;

parameters beta gamma delta alpha phi_pi kappa;

hetagent_block;
  model = "hank_two_asset";
  inputs = r, w;
  outputs = C;
  steady_state = "hank_steady_state";
end;

model;
  Y = C + I;
  K = (1 - delta)*K(-1) + I;
  w = (1 - alpha)*Y;
  r = alpha*Y/K(-1) - delta;
  pi = beta * pi(+1) + kappa * (Y - 1);
end;
```

### 3.2 Coupling the Aggregate DAG with Sequence-Space Jacobians
1. **Steady State**: Solves the microeconomic stationary distribution $\mathcal{D}^*$ and aggregate market clearing simultaneously.
2. **Jacobian Integration (Fake-News Algorithm)**:
   Using `puremacro.models.hank_sequence_space`, compute the sequence-space Jacobian matrices:
   $$\mathcal{J}_{C, r} = \frac{\partial \mathbf{C}}{\partial \mathbf{r}} \in \mathbb{R}^{T \times T}, \quad \mathcal{J}_{C, w} = \frac{\partial \mathbf{C}}{\partial \mathbf{w}} \in \mathbb{R}^{T \times T}$$
3. **Stacked Linear & Nonlinear System**:
   Integrate $\mathcal{J}$ into the perfect foresight Newton / Broyden solver (`puremacro.dsge.perfect_foresight` and `hank_sequence_space`), solving MIT shock transitions in seconds without state-space curse of dimensionality.
