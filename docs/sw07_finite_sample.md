# SW07 finite-sample diagnostics

This experiment examines how the [observed-data SW07 study](empirical_research.md)
behaves in samples of 156 quarters generated by specified model calibrations.
It compares the observed minimum-distance criterion with simulated criteria,
checks how estimating sample means changes empirical covariance moments, and
compares estimated HAC covariance with Monte Carlo sampling covariance.

The exact Gaussian calculation can be used independently of the simulation:

```python
from puremacro.structural import sw07_finite_sample_moments, simulate_sw07_sample

exact = sw07_finite_sample_moments({}, nobs=156, common_max_lag=4)
print(exact.labels[0], exact.values[0])
print(exact.covariance.shape)  # Joint sampling covariance of 15 moment estimates.
sample = simulate_sw07_sample({}, nobs=156, seed=20261001)
print(sample.shape)
```

An empty parameter mapping uses the declared Pfeifer calibration. Exact first
and second moments do not make these quadratic estimators normally distributed.

```bash
python -m puremacro.examples.sw07_finite_sample \
  --replications 399 --seed 20261001 \
  --output research_output/sw07_finite_sample
```

The experiment is substantially more expensive than loading a frozen benchmark:
each replication refits two parameters from four optimizer starts. Start with
a small replication count to check a workflow; use enough draws for the desired
Monte Carlo precision before interpreting a tail fraction. The CLI reports
progress and does not download data.

The application saves atomic checkpoints under the output directory after the
first draw, every ten draws and scenario completion. Rerunning the same command
resumes saved draws. Changed settings, numerical source files or dependency
versions require a fresh run (`--no-resume`). Full per-start optimizer messages
and reasons are retained in `draws.csv` as `start_diagnostics_json`.

## What is held constant

Each draw repeats the empirical study's sample length, estimated full-sample
means, common product window, nine fitted moments, six unused moments,
parameter bounds, and optimizer settings. The default fitting covariance uses
Bartlett HAC with bandwidth eight. Innovations are independent Gaussian model
innovations, and simulations initialize from the stationary distribution.
Economic measurement error is excluded, as in the observed-data study.

The estimated parameters remain `crr` (interest-rate smoothing) and `em`
(monetary innovation standard deviation). Other structural coefficients and
shock variances are held at explicitly recorded values. All selected series
use quarterly percent units.

| Scenario | Generating parameters | Interpretation |
|---|---|---|
| `baseline_fixed` | Declared Pfeifer calibration | Diagnostic for this specified fixed model |
| `published_fixed` | Rounded published SW07 mode | Diagnostic for this specified fixed model |
| `baseline_fitted` | Baseline calibration with observed-data fitted `crr` and `em` | Descriptive plug-in diagnostic |
| `published_fitted` | Published calibration with observed-data fitted `crr` and `em` | Descriptive plug-in diagnostic |

Select one or more scenarios with repeated flags:

```bash
python -m puremacro.examples.sw07_finite_sample \
  --scenario published_fixed --scenario published_fitted \
  --replications 399 --seed 20261001 --bandwidth 8 \
  --output research_output/sw07_published_diagnostics
```

Fitted scenarios depend on the observed sample. Their exceedance fractions are
**not validated bootstrap p-values or composite-null tests**. Published
calibration parameters were estimated using overlapping historical data;
their uncertainty is not incorporated. The study does not externally identify
monetary shocks or replicate the paper's Bayesian posterior.

## Read the simulation results

The report retains observed fits, simulated estimates, optimizer diagnostics,
bound hits, and computational failures. A successful optimizer does not imply
empirical adequacy. A scientific rejection is a valid completed experiment;
the CLI returns a nonzero status for computational failures, rather than for
an unfavorable scientific result.

Read tail fractions together with their **binomial Monte Carlo intervals**.
These intervals quantify randomness from the finite number of simulations.
They are not confidence intervals for `crr` or `em`, and they omit uncertainty
about the fixed calibration, data vintage, structural specification, and regime
stability. Zero simulated exceedances do not establish a zero underlying tail
probability. Computational failures cannot silently enter the denominator as
successful non-exceedances.

The observed series come from the bundled revised FRED snapshot, covering
1966Q1–2004Q4. Stationarity and constant parameters across that historical
sample are assumptions. Simulated samples obey those assumptions by construction;
the historical observations need not.

## Completed diagnostic: 2026-10-01

The four-scenario run used 399 replications each and seed 20261001. All 1,596
moment/HAC constructions completed; 22 fits remained numerically unresolved.
The ranges below count each unresolved draw first as a non-exceedance and then
as an exceedance. Monte Carlo intervals also account for simulation randomness.

| Scenario | Observed criterion | Unresolved / 399 | Exceedance fraction range | Conservative 95% Monte Carlo interval |
|---|---:|---:|---:|---:|
| `baseline_fixed` | 396,736.10 | 4 | 0–1.00% | 0–2.55% |
| `published_fixed` | 25.26 | 9 | 41.60–43.86% | 36.72–48.88% |
| `baseline_fitted` | 396,736.10 | 2 | 0–0.50% | 0–1.80% |
| `published_fitted` | 25.26 | 7 | 39.35–41.10% | 34.52–46.11% |

The declared baseline remains an extreme mismatch. For the fixed published
calibration, the observed criterion is common in the simulated distribution,
despite its small asymptotic J p-value in the earlier study. The nominal 5%
chi-square rule rejects 62.16–64.41% of these model-generated samples. Even
among the 383 numerically regular fits, it rejects 241 (62.92%). Numerical
regularity does not repair this finite-sample distortion.

Under that published calibration, mean bandwidth-eight HAC estimates are only
55.6% and 52.5% of the exact sampling variances of the inflation-variance and
interest-rate-variance estimators. Demeaning also lowers their expected moments
by 0.67 and 0.70 sampling standard deviations. These are contributing
diagnostics, not a causal decomposition of the rejection rate. A larger HAC
bandwidth alone has not been validated as a remedy.

This result changes the interpretation of the earlier asymptotic diagnostic;
it does not establish model adequacy or restore parameter confidence intervals.
The repository dossier `reviews/2026-10-01-sw07-finite-sample/` preserves the
protocol, individual draws, exact references, source audit, hashes and reports.

The subsequent [paired estimator experiment](sw07_estimator_experiment.md)
separates finite-sample expectation corrections from covariance weighting.
Independent validation finds substantial improvement with known-DGP covariance
weights, but even those weights do not restore the nominal chi-square reference.

## Diagnose moments and weights

`moment_audit.csv` separates stationary model moments, exact finite-sample
expectations, and simulated empirical moments. Their differences reflect finite-sample construction,
including full-sample demeaning, rather than a numerical change to the
Lyapunov solution. The observation matrix differences GDP levels into growth
and leaves quarterly inflation and interest rates in levels, following the
[SW07 measurement equations and data appendix](https://www.ecb.europa.eu/pub/pdf/scpwps/ecbwp722.pdf).

`covariance_audit.csv` compares the exact Gaussian finite-sample covariance,
Monte Carlo covariance of the empirical moment estimators, and mean HAC
covariance estimates. Bandwidths four, eight, and
twelve are audited without refitting for every audit bandwidth. These are
covariances of estimated moments, with their cross-moment terms retained;
they are not unscaled long-run covariances.

The declared calibration must not be confused with the published mode.
For example, the [Pfeifer source](https://github.com/JohannesPfeifer/DSGE_mod/blob/master/Smets_Wouters_2007/Smets_Wouters_2007.mod)
uses risk-premium innovation standard deviation 1.8513 in its shock block,
distinct from its estimation starting value and the paper's reported mode.
The data/mapping audit found this fixed shock scale dominates the declared
calibration's GDP-growth variance. A nearly persistent technology process and
the sampling properties of demeaned moments are separate issues; persistence
alone should not be used to explain every discrepancy.

`draws.csv` includes an `array_row` key linking each replication to its row in
the NPZ arrays. The manifest records moment labels and array dimensions. Moment
and HAC audits can use successfully constructed moments even if optimization
later fails; their available-draw counts must be distinguished from usable fits.

The report also shows parameter bias and RMSE among usable fits and two
asymptotic-rule diagnostics. The naive chi-square(7) rejection rate includes
boundary fits deliberately; it does not provide valid boundary inference.
The regular J rejection rate conditions on the numerically regular subset,
whose denominator is reported. Neither diagnostic establishes general test
size or coverage.

JSON represents unavailable numerical diagnostics as `null`. The CSV draw rows
and binary arrays retain evidence needed to audit missing or failed outcomes.
Numerical reference tests and the statistical experiment remain distinct: an
unfavorable model diagnostic does not establish a software defect.
