# puremacro Batch 6 — Native X-11/ARIMA seasonal adjustment (pure Python, Pyodide-safe)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the Fortran-binary dependency for X-13-class seasonal adjustment. Implement the X-11 decomposition engine and an airline-model regARIMA pre-adjustment natively (numpy + the house Kalman in `puremacro.state_space`), validated against the real X-13ARIMA-SEATS binary via frozen goldens. Result: the SA method hierarchy becomes binary → **native X-11/ARIMA** → STL, with the native engine as the Pyodide default. No pure-Python X-11 exists anywhere in the ecosystem — this is a flagship feature.

**Why it is feasible:** JDemetra+ (Eurostat/ECB's official tool) reimplemented X-11 and TRAMO/SEATS natively in Java — the existence proof. The X-11 chain is documented table-by-table in Ladiray & Quenneville (2001); X-13 is public-domain US-government work. The genuine binary (v1.1.57, installed 2026-07-21 under `~/.local/x13ashtml/` with the `~/.local/bin/x13as` statsmodels naming bridge) is the golden generator — CI and Pyodide never need it, only frozen goldens.

**Honest naming:** the deliverable is "X-11/ARIMA-style, X-13-validated" — NOT a claim to the whole X-13 program. automdl beyond the airline default, trading-day/Easter regressors, and SEATS are explicitly out of scope for v1 (SEATS is its own project: canonical decomposition + polynomial spectral factorization).

## Architecture / v1 design decisions (pre-registered)

1. **regARIMA v1 = airline model** SARIMA(0,1,1)(0,1,1)_s, exact Gaussian MLE. State space: for w = (1-B)(1-B^s)y, MA(q) with q = s+1, c₁ = −θ, c_s = −Θ, c_{s+1} = θΘ; state = (ε_t, …, ε_{t−q})' (dim q+1), T = shift, Z = (1, c₁, …, c_q), exact stationary init P0 = σ²I (states are white noise — no diffuse issues), tiny H ridge per house convention. Optimize (θ, Θ, log σ²) with L-BFGS-B, |θ|,|Θ| ≤ 0.98. Forecasts of w directly from the filtered terminal state (it IS (ε̂_T, …)); integrate (1−B)(1−B^s) forward. Backcasts: same params on the time-reversed series (ARIMA autocovariance is time-reversible).
2. **transform 'auto'** = log vs level by AICC including the log-Jacobian term (Σ log y), exactly X-13's `transform{function=auto}` comparison. Multiplicative X-11 with log-ARIMA, additive with level.
3. **End handling v1 = long symmetric extension**: 60 periods of fore/backcasts (covers 2×12-MA (6), Henderson-23 (11), and 3×9 seasonal MA (5 years) half-widths), so every ORIGINAL observation gets symmetric filters. This will NOT bit-match the binary's default 1-year-extension + asymmetric end filters near the boundaries — goldens therefore check interior points tightly and the first/last 2 years loosely (tolerances recorded per series in the golden file). v2 upgrade path: transcribe the Ladiray-Quenneville asymmetric seasonal end-weight matrices + Musgrave Henderson ends (do NOT write these matrices from memory — transcribe from the book/manual or derive from the binary's published filter output).
4. **X-11 chain** (B → C → D iterations, multiplicative or additive): 2×period initial trend; SI; extreme-value replacement with 1.5σ/2.5σ moving five-year sigma limits (zero/linear weights, replacement = weighted same-calendar-period neighbours); seasonal composite MAs 3×3 → 3×5 with normalization by centered 2×period MA; Henderson trend with I/C-ratio length selection (monthly 9/13/23 at cuts 1.0/3.5; quarterly 5/7); final seasonal filter by global MSR (cuts 2.5/3.5/5.5/6.5 with the cut-a-year retry ≤5, undecided → 3×5); D10/D11/D12/D13 outputs. Henderson weights from the closed-form polynomial formula, unit-tested against the published 13-term weights.
5. **Golden validation ladder** (`tools/gen_validation_goldens_sa.py`): binary runs PINNED to the native spec first — `transform{function=log|none}`, `arima{model=(0 1 1)(0 1 1)}`, `outlier` OFF, `x11{seasonalma=msr}` — on (a) the classic airline-passengers series, (b) 6–10 county U/E series from the batch-4 panel spanning big/small/noisy, (c) 2 quarterly series. Frozen as CSV goldens + tolerance table. Tests: `tests/test_sa/test_x11_native.py` — Henderson weights exact; airline MLE θ/Θ vs binary-reported estimates (loose, different optimizers); D10/D11 interior agreement within frozen tolerances; mult vs add; group API parity with `deseasonalize_x13` contract. Iterate implementation until interior tolerances are tight (target: max rel err < 1% on D11 interior for well-behaved series; record achieved values, don't promise before measuring).
6. **Public API**: new module `puremacro/sa/x11.py` — `x11_arima()` returning frozen `X11Result` (sa, trend, seasonal, irregular, mode, chosen filters, MSR, I/C, arima params) + `deseasonalize_x11(df, value_col, by=, date_col=, freq=)` mirroring the stl/x13 group contract. `puremacro/sa/_airline.py` internal. Snapshot regenerated ONCE for the additive drift (house precedent, Notes entry in CHANGELOG). `sa/x13.py` fallback order becomes binary → `x11_arima` → STL, with the source recorded so callers can tell which engine produced a series.
7. **Outliers**: v1 ships `outlier=False` only (goldens pinned accordingly). AO/LS detection (forward-add t>3.8-ish critical, backward-delete) is task 6, feature-flagged, with its own goldens.
