# SW07 estimator controls

The [finite-sample diagnosis](sw07_finite_sample.md) found severe distortion of
the original chi-square reference in samples generated by the published SW07
calibration. This experiment separates changes to the model's expected moments
from changes to its covariance weights, using the same sample for every variant.

| Variant | Model moments during fitting | Covariance used as weights |
|---|---|---|
| `population_hac` | Stationary population covariances | Each sample's HAC8 estimate |
| `finite_hac` | Exact expectations of the sample-centered moments | Each sample's HAC8 estimate |
| `population_oracle` | Stationary population covariances | Exact covariance at the known DGP, held fixed |
| `finite_oracle` | Exact expectations of the sample-centered moments | Exact covariance at the known DGP, held fixed |

The oracle weights are a diagnostic control. They use the true generating
parameters and are not an estimated, feasible covariance procedure. Exact first
and second moments do not make the estimators normally distributed or establish
a chi-square specification test. No replacement of the existing empirical
estimator or parameter confidence interval is selected automatically.

## Fast exact expectations

The expectation-only helper avoids constructing the full covariance of moment
estimators inside optimization. It uses autocovariance prefix sums to account
exactly for estimated full-sample means and the common product window:

```python
from puremacro.structural import sw07_finite_sample_expectations

expected = sw07_finite_sample_expectations({}, nobs=156, common_max_lag=4)
print(expected.shape)  # 15 expected sample covariance moments
```

An empty mapping selects the declared Pfeifer calibration. The controlled
experiment instead explicitly uses the complete rounded published calibration,
with generating parameters `crr=0.81`, `em=0.24`. The remaining parameters are
fixed, and their uncertainty is not propagated.

## Independent phases

The recorded design uses 399 calibration samples and 999 independent validation
samples, each containing 156 stationary Gaussian quarters. All four variants
share each sample and its complete 15-moment HAC matrix. They retain the original
nine fitted moments, six reserved moments, bounds and four optimizer starts.

```bash
python -m puremacro.examples.sw07_estimator_experiment \
  --phase calibration --replications 399 --seed 20261002 \
  --output research_output/sw07_controls/calibration

python -m puremacro.examples.sw07_estimator_experiment \
  --phase validation --replications 999 --seed 20261002 \
  --calibration research_output/sw07_controls/calibration \
  --output research_output/sw07_controls/validation
```

Phase indices give distinct random streams even with the same master seed.
Small runs are useful only for workflow checks. The API
`run_sw07_estimator_experiment` runs one phase;
`compare_sw07_estimator_phases` applies the calibration reference to validation.
The CLI authenticates every artifact hash before loading a reference phase.

Atomic checkpoints save the first draw, every ten draws and completion. Resume
requires identical numerical sources, settings, data and dependency versions.
Use `--no-resume` for a fresh run. A nonzero CLI status reports unresolved
numerical outcomes, even when every requested replication and export completed.

## Interpretation

`summary.csv` reports the deliberately naive chi-square(7) rejection frequency,
optimizer failures, boundaries and parameter recovery. Rate bounds count every
unresolved fit both ways. Parameter bias/RMSE and criterion quantiles condition
on usable fits. `paired_differences.csv` compares squared errors on common usable
draws and reports that denominator; its standard errors measure Monte Carlo
variation. Different covariance weights give criteria with different scales.

The calibration cutoff uses rank `ceil(0.95*(B+1))` and strict rejection above
that order statistic. Unknown calibration criteria lie between zero and
infinity, producing an interval for the cutoff. Validation lower/upper rejection
counts also retain unresolved validation fits. `calibrated_validation.csv`
records both sources of ambiguity and conservative Clopper–Pearson intervals.
These intervals condition on the realized calibration pool; they do not capture
all uncertainty from estimating the cutoff. Very small or incomplete reference
samples can produce infinite cutoffs, explicitly flagged as unbounded.

Validation uses new draws, but only at one known DGP. It does not establish a
composite-null test, nuisance-parameter robustness, economic model adequacy or
general coverage. Fitting the observed revised FRED data is descriptive, and
the published calibration overlaps the historical estimation sample. No
ordinary parameter inference is restored by a favorable simulation result.

## Completed comparison: 2026-10-01

The predeclared run completed 399 calibration and 999 independent validation
samples: 1,398 samples shared across four variants, giving 5,592 fitted results.
The independent audit reproduced all rates, failure bounds, paired comparisons
and frozen cutoffs from saved artifacts. Validation results are:

| Variant | Unresolved / 999 | Rejection using nominal 5% chi-square rule | Rejection using separate simulation cutoff |
|---|---:|---:|---:|
| `population_hac` | 22 | 61.56–63.76% | 2.20–5.51% |
| `finite_hac` | 8 | 40.94–41.74% | 2.30–6.51% |
| `population_oracle` | 0 | 7.71% | 4.90% |
| `finite_oracle` | 0 | 8.21% | 5.91% |

Correcting expected moments alone leaves severe rejection distortion with HAC.
Oracle weights reduce it substantially, but their naive-rule 95% Monte Carlo
intervals, 6.13–9.54% and 6.58–10.09%, remain above 5%. Even exact means and
covariance therefore do not restore the chi-square approximation. Simulation
cutoff intervals are 3.65–6.43% and 4.53–7.55% for the two oracle variants,
conditional on the recorded calibration pool and the known DGP.

The finite-expectation correction improves paired parameter squared error under
HAC, but worsens it under oracle weights for both parameters in validation.
There is no universal parameter-risk improvement. All 46 unresolved fits across
both phases fail the additional first-order optimization check despite reported
optimizer success; they remain in the bounds. All generating dynamics are
stationary. No estimator is automatically adopted and no ordinary parameter
intervals are restored. A feasible estimated-weight procedure and uncertainty
about nuisance calibration require separate validation.

`draws.csv` preserves all optimizer starts, sample hashes and seeds. Its
`array_row` links all four variants to the shared moments and HAC covariance in
`draw_evidence.npz`. `manifest.json` records the known oracle covariance, source
hashes, generating parameters, environment and artifact hashes; `report.md`
and `estimator_comparison.png` present the outcomes. The full research protocol
and completed evidence are retained under
`reviews/2026-10-01-sw07-estimator-experiment/` in the repository.
