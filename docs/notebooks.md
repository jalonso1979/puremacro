# Showcase notebooks

Choose an economic question, run one example, and then change an assumption.
The catalog links to executed notebooks and their editable Python sources in
both languages. The `00` notebooks describe earlier releases; they are historical
tours, not the starting point for the current package.

## Run and change an example

From a repository checkout, install the notebook tools and a notebook interface:

```bash
python -m pip install -e ".[notebooks]" jupyterlab
python -m jupyterlab notebooks
```

Select the kernel for that environment. Keep `notebooks/_nbstyle.py` beside the
showcases; several examples also use bundled files from the repository. Open an
`.ipynb`, restart its kernel, and run all cells before changing an exercise.

The `.py` files in Jupytext percent format are the editable sources. Rebuild
both languages after an edit:

```bash
python tools/build_notebooks.py 34_penalized_macro_forecasting 34_penalized_macro_forecasting_es

# Execute to temporary artifacts and validate their outputs.
python tools/build_notebooks.py --check 34_penalized_macro_forecasting 34_penalized_macro_forecasting_es

# Inspect existing artifacts without executing them.
python tools/build_notebooks.py --validate-only
```

`--suite showcase` selects the top-level showcases and `notebooks/course/`;
`--suite curso` selects `curso/notebooks/`. Without a name or suite, the tool
processes both suites.
Build individual examples first: simulation, bootstrap and Bayesian examples
have different computation costs. For browser execution, consult the
[tablet and Pyodide guide](tablet.md). Local LLM inference requires a desktop
engine; its mock fallback demonstrates the interface only.

## Read the evidence before the conclusion

Check the data provenance, observation units, estimand, and uncertainty measure
before interpreting a chart. Country labels and realistic dates do not make
simulated observations empirical evidence. Fixed seeds reproduce an experiment;
they do not establish its accuracy or generality.

- **10 — DiD:** the overall ATT needs uncertainty for its own aggregation. The
  event-study bands are pointwise. An interval can miss the planted truth in one
  simulated sample.
- **34 — forecasting:** compare predictions for later, unused observations with
  a simple benchmark. In-sample fit and variable selection answer other questions.
- **48 and 59 — nowcasting:** 48 holds target GDP out of bridge estimation and
  labels its single-vintage projection contributions as diagnostics. Exact news
  attribution requires two information sets under a fixed model, as in 59. Its
  separate simulated PIT experiment does not validate the actual nowcast
  densities. These are synthetic examples, not official forecasts.
- **50 — fiscal analysis:** identify the shock before interpreting an impulse
  response as a multiplier. Debt ratios, percentage points and decimal changes
  must use consistent units; the debt scenarios impose their own assumptions.
- **61 and 62 — policy simulations:** the small trade preset in 61 is hand-built;
  62 inspects bundled OECD data, then separates flexible building blocks from
  a small synthetic benchmark solve. With an active flexible setting,
  `solve_flexible_trade_equilibrium` uses the quasi-condensed solver on
  calibrations of up to 100 country-sector cells, or at any size with
  `method="quasi_condensed"` (dense Newton). On larger tables without an
  explicit method, or with another `method`, it raises `ValueError`;
  `allow_legacy_fallback=True` returns the legacy equilibrium flagged
  `flexible_settings_applied=False`. Final-demand sourcing stays
  fixed-coefficient unless `sigma_trade` is set. Compare flexible runs with the
  default configuration solved at `replicate_matlab_precedence=False`: the
  default call keeps the MATLAB operator-precedence convention, whose
  producer-price responses are five to twelve times larger on notebook 62's
  2x2 economy (about seven times on the largest response). Report nominal wages, price-deflated wages, output and welfare
  according to their definitions.
- **63–65 — advanced trade:** 63 audits tariff-game best responses; 64 separates a
  scalar toy fold from synthetic CGE continuation; 65 demonstrates Hicksian
  EV/CV and endpoint attribution. The historical TOT/Alloc/TariffRec decomposition
  and theorem certification remain unavailable. See
  [structural validation status](STRUCTURAL_VALIDATION_STATUS.md).
- **66 — optimal policy:** the closed-form checks show that the policy solvers
  implement the Clarida–Galí–Gertler formulas at any admissible calibration.
  By default `stabilization_bias` compares unconditional losses. At low discount
  factors that criterion ranks timeless commitment below discretion, although
  commitment still wins when the loss is evaluated from the steady state, which
  `loss_criterion="conditional"` does.
- **67 — Bewley classics:** Aiyagari's Table I is reproduced exactly and every
  ordering in Aiyagari's Table II and Huggett's tables holds, but their decimals
  differ by more than the notebook's numerical error. At high persistence, the
  choice of Markov chain moves Aiyagari's rates by more than those differences.
- **68 — third order:** matching simulated paths does not show that a tensor is
  right; the notebook compares every tensor with closed forms and with live Dynare
  output. The exact pruned moments match a closed form and Dynare's means and
  variances. Dynare's order-3 autocorrelations do not: a closed form and Dynare's
  own long simulations both reject them. Skewness and kurtosis still come from
  simulations.
